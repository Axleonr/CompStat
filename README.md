# CompStat

A self-learning Computational Statistics course, made with LLM assistance.

The course material is divided across 11 modules, and has both a theory and practice component. Because AI was used in this project, all theory is presented in the form of assigned readings from published or widely available publications, and reviewed manually; because of this, there should be no misinformation in this course caused by hallucinating facts. Please note that bias from the model in the readings selection is unaccounted for.

The practice section is a series of Problem Sets, one for each of modules 0 through 9. The problems were machine drafted from verifiable sources and carry a verification protocol in the Instructor section, again, to minimize risk of misinformation.

- All material is procedurally verified at the very least. 

- Most material is human-verified. Complete human verification is a WIP. 

- Internal contains backend material used in program design and refinement.

## Where to start

Everything you need as a student is in `\Course Material`. Begin by reading the Program Orientation Note.
